# Goals

## Product Goal

Build Nexus into an AI-native productivity and knowledge operating system that helps Kofi retrieve, understand, plan, and act on durable personal and project context without surrendering control of the source material to a proprietary database.

## Near-Term Goals

1. Establish the Nexus application foundation.
2. Establish this Vault as the canonical Markdown knowledge store.
3. Support deterministic project discovery and document retrieval.
4. Add controlled GitHub-backed writes only after read paths and contracts are verified.
5. Add NVIDIA reasoning for synthesis, planning, and project questions after deterministic context selection is reliable.

## Quality Goals

- The Vault remains understandable in GitHub alone.
- AI output is traceable to selected context.
- Every project has a consistent operating contract.
- Planning reflects actual tasks and project state.
- Product decisions are durable and reviewable.
- The system can grow without requiring a full knowledge-store migration.

## Longer-Term Direction

Nexus should become a coherent interface over identity, projects, daily notes, planning, knowledge, people, and operational records. This is a direction, not a claim that those capabilities are already implemented.
