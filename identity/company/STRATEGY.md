# Nexus Strategy

## Strategic Thesis

A personal knowledge system is more trustworthy and durable when the canonical content remains readable, versioned, and user-controlled. Nexus therefore treats AI as a reasoning layer over selected context rather than as the database itself.

## Current Strategy

1. Establish reliable GitHub-backed read paths.
2. Standardise project and registry contracts.
3. Build a useful client and API foundation.
4. Add controlled mutation workflows after read behaviour is verified.
5. Add NVIDIA reasoning for synthesis, planning, and question answering.
6. Expand into daily planning, notes, people, and broader knowledge without abandoning Markdown portability.

## Explicit Non-Goals For The Foundation

- Competing with general-purpose document editors
- Building a vector database before it is necessary
- Making AI responsible for exact retrieval
- Introducing authentication before the owner-only workflow requires it
- Claiming autonomous completion without verification
