# Glossary

- **Nexus** — the application and broader productivity operating system.
- **Vault** — this canonical Markdown knowledge repository.
- **Registry** — deterministic indexes used to discover projects, documents, agents, and tags.
- **Project contract** — the standard set of files that gives each project durable context and operating instructions.
- **Deterministic retrieval** — exact selection of known files or records without generative AI.
- **Reasoning layer** — NVIDIA-backed synthesis or generation over deliberately selected context.
- **Foundation MVP** — the first application milestone covering the client shell, Express API, health endpoints, and read-only Vault project listing.
- **Current state** — verified present reality, distinct from plans or authored but unverified implementation.
