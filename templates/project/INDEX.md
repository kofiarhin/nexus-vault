# Project Template

## Snapshot

State the project's purpose, owner, repositories, lifecycle state, and current focus.

## Read Order

1. `AGENT.md`
2. `PROJECT.md`
3. `TASKS.md`
4. `ROADMAP.md`
5. relevant supporting documents
6. `CHANGELOG.md`

## Supporting Directories

Create only when useful: `docs/`, `decisions/`, `research/`, `meetings/`, `learnings/`, `prompts/`, `workflows/`, `assets/`, and `archive/`.
