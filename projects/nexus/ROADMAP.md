# Nexus Roadmap

## Phase 1 — Foundation

- Application repository bootstrap
- React/Vite client shell
- Express MVC API
- Environment validation and standard API envelopes
- Read-only GitHub Vault integration
- Deterministic project listing
- Canonical Vault structure and real Nexus project record

## Phase 2 — Verified Read Experience

- Resolve dependency installation
- Run automated tests and client build
- Verify application-to-Vault integration
- Add deterministic document reading and bounded search
- Improve client project navigation

## Phase 3 — Controlled Knowledge Writes

- Define write authority, validation, revision checks, and conflict handling
- Add document updates
- Add project creation from the standard contract
- Preserve GitHub commit evidence for every mutation

## Phase 4 — Reasoning And Planning

- Integrate NVIDIA reasoning
- Add project question answering over selected context
- Add plan generation
- Produce `planning/TODAY.md` from real tasks, projects, and daily notes

## Phase 5 — Broader Personal Operating System

- Daily notes
- Knowledge and areas
- People context
- Search improvements
- Authentication when access expands beyond the initial owner-only workflow

Roadmap phases express intended sequence, not committed dates.
