# Nexus Vault

The canonical Markdown knowledge repository for Nexus and Kofi's working context.

## Start Here

1. Read `NEXUS.md` for the operating model.
2. Read `identity/INDEX.md` for durable owner and product context.
3. Use `registry/PROJECTS.md` for deterministic project discovery.
4. Open the selected project's `INDEX.md` and `AGENT.md`.
5. Load only the documents required for the active task.

## Current Project

- `projects/nexus/` — the real Nexus project record, decisions, tasks, roadmap, and implementation status.

## Repository Map

- `identity/` — Kofi's confirmed working profile, preferences, goals, and Nexus product context
- `registry/` — deterministic project, document, agent, and tag indexes
- `projects/` — durable project operating records
- `planning/` — current selected plans
- `daily/` — dated work and reflection notes
- `knowledge/` — reusable reference knowledge
- `areas/` — ongoing responsibilities
- `people/` — explicitly supplied relationship context
- `templates/` — reusable document and project contracts
- `system/` — Vault schemas, naming, and write rules
- `assets/` and `archive/` — supporting resources and historical material

## Integrity Rules

- Markdown and Git history are the source of truth.
- Deterministic retrieval comes before AI reasoning.
- Missing facts are not invented.
- Ideas, decisions, assumptions, implementation, verification, merge, and deployment remain distinct.
- Secrets never belong in this repository.
